## 🚀 Quick Start

✅ Verified Compatible Versions:
- Python 3.9.13 
- Node.js v16.14.2+
- npm 8.5.0+

ℹ️ Lower/higher versions may work but haven't been thoroughly tested


## 🛠 Installation Guide

### 1. Clone Repository
```bash
git clone -b english_version https://github.com/Julie3399/stock_monitor.git
cd stock-monitor
```
### 2. Initialize Environment
```bash
bash setup.sh
```
📌 The script will automatically:
- Install Python dependencies
- Install Node modules

## 🔥 Usage Guide
Start the system
```bash
python run.py
```
📌 The script will automatically:
- Start backend service
- Start frontend service
- Open browser and display platform interface
